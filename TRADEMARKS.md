Cette licence porte **uniquement sur le code**. Elle ne donne **aucun droit** sur le nom « Bible Plan », le logo, les icônes ou l'identité visuelle du projet (les « Marques »).

Cette politique a deux buts : éviter toute confusion pour les utilisateurs et protéger la réputation du projet, sans freiner l'usage libre du code.

## Ce que vous pouvez faire sans autorisation

- Dire que votre logiciel est « basé sur Bible Plan » ou « un fork de Bible Plan », de façon factuelle.
- Mentionner le projet dans un article, une vidéo, une présentation ou une documentation.
- Faire un lien vers le dépôt officiel ou le site officiel.
- Utiliser les Marques sans modification pour parler du projet officiel.

## Ce qui nécessite une autorisation écrite

- Distribuer ou héberger une version **modifiée** sous le nom « Bible Plan » ou avec son logo.
- Utiliser les Marques dans un nom de produit, de service, de domaine, de compte de réseau social ou d'application sur un store.
- Utiliser les Marques d'une manière qui laisse croire à un partenariat, un soutien ou une approbation officielle.
- Utiliser les Marques sur des produits commerciaux (goodies, publicités, etc.).

## Forks

Les forks sont les bienvenus : c'est l'esprit de l'AGPL. Si vous publiez ou hébergez une version modifiée, vous devez :

1. lui donner un **nom différent** et retirer le logo officiel ;
2. respecter l'AGPL, notamment fournir le code source de votre version à vos utilisateurs réseau (section 13) ;
3. conserver les mentions de copyright et le fichier [NOTICE](NOTICE).
